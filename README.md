## Descrição da atividade

Desenvolvimento de uma aplicação utilizando o framework Flutter, com o objetivo de praticar a criação de interfaces, utilização de widgets e organização básica de um projeto Flutter.

## Descrição da aplicação

A aplicação desenvolvida é uma aplicação simples em Flutter que apresenta uma tela inicial contendo uma AppBar e uma mensagem de boas-vindas. O projeto utiliza widgets do Material Design para construir a interface.

## Principais funcionalidades implementadas

- Exibição de uma AppBar com o título "Meu App";
- Exibição da mensagem "Olá, Mundo!";
- Personalização das cores e estilos da interface;
- Utilização do `MaterialApp` e `Scaffold`;
- Organização da interface utilizando widgets como `Container`, `Center` e `Text`.

## Instruções básicas para execução

### Pré-requisitos

- Flutter instalado e configurado;
- Dart SDK;
- Um dispositivo físico ou emulador configurado;
- Editor de código, como Visual Studio Code ou Android Studio.

### Execução

1. Clone o repositório:

```bash
git clone URL_DO_REPOSITORIO
```

2. Acesse a pasta do projeto:

```bash
cd nome-do-projeto
```

3. Instale as dependências:

```bash
flutter pub get
```

4. Execute a aplicação:

```bash
flutter run
```

Para executar no navegador:

```bash
flutter run -d chrome
```
